## 立即试用

下载本仓库的 changeguard_trial.py，或到 Releases 下载免费 ZIP。需要 Python 3.9+ 和独立安装的 Git，无第三方 Python 包、API Key、模型调用、网络上传或遥测。

在**你自己的**已有 Git 仓库中运行：

```sh
python3 changeguard_trial.py --version
python3 changeguard_trial.py --repo /path/to/your/repo
```

Windows 可以用 `py -3` 替代 `python3`。报告输出到终端；若要保存，可在本人选定目录重定向输出。工具只读 Git，不替你暂存、提交或执行项目测试。

免费版只读取**已经暂存**的变更，按路径生成鉴权、数据迁移、部署检查提醒。重命名按删除和新增显示。未暂存/未跟踪文件不在报告内；可能误报和漏报，不分析代码语义/真实依赖，也不证明安全。不要求用公司源码试用。
